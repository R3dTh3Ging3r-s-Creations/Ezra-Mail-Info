# Ezra Mail

Ezra Mail is a self-hosted email and calendar assistant with local AI-assisted
triage, daily briefs, and tools for reviewing and handling mail.

You run Ezra Mail in an environment you control and choose which provider
accounts to connect. Access to Microsoft or Google account data depends on
the permissions you grant and any policies set by your organization.

Ezra Mail does not operate a hosted mailbox service. It is pre-1.0 software
with no support SLA or guarantee that every provider or setup is supported.
